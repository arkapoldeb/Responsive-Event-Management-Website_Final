# 🎉 Eventora — Responsive Event Management Website

**Discover Events. Book Tickets. Create Memories.**

Eventora is a modern, responsive event management website designed to help users explore upcoming events, discover event information, and book tickets through an interactive and user-friendly interface.

Developed as part of the **K Explore – Web Designing Challenge**, this project focuses on modern web design, responsive layouts, interactive JavaScript functionality, and a smooth event booking experience.

---

## 📌 Project Overview

Eventora provides a simple and engaging platform for discovering events and booking tickets.

Users can explore different events, view event details, navigate to a dedicated booking page, and experience a streamlined ticket booking process.

The website is designed to provide a consistent experience across desktop computers, laptops, tablets, and mobile devices.

## 🚀 How to Run the Project

### Method 1: Using Visual Studio Code

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. The Eventora website will open in your browser.

### Method 2: Using Python

Open the VS Code terminal inside the project folder.

Execute:

```bash
python -m http.server 5500
```

Open your browser and visit:

```text
http://localhost:5500
```
